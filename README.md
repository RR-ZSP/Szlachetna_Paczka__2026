# Szlachetna Paczka 2026 — RR-ZSP

Ten projekt będzie udostępniał świąteczny formularz darczyńców na GitHub Pages z zapisem do prywatnego arkusza Google Sheets.

**Status: prace wdrożeniowe — formularz nie jest jeszcze gotowy do zbierania zgłoszeń.**

## Ważne

- Strona w `docs/` wymaga ukończenia pliku `app.js` i skonfigurowania publicznego endpointu w `config.js`.
- Backend Google Apps Script z `apps-script/Code.gs` wymaga wdrożenia jako aplikacja internetowa.
- W arkuszu Google w zakładce `Ustawienia` wartość `FORM_OPEN` musi pozostać `NIE` do zakończenia testów.
- Lista produktów pochodzi z archiwalnego 2025 roku. Nie uruchamiaj zapisów przed jej aktualizacją oraz uzupełnieniem informacji RODO.
- Dane darczyńców nie mogą być umieszczane w publicznym repozytorium.

Dla użytkownika dostępna jest kompletna paczka plików projektu z instrukcją. Przed startem trzeba wgrać aktualne pliki aplikacji, wdrożyć backend, uruchomić GitHub Pages i przetestować rezerwacje na dwóch urządzeniach.
